# Laravel

1. **Follow Laravel's conventions to the letter** - naming (singular model, plural table, `snake_case` columns), directory structure, artisan generators (`make:model -mfs`, `make:request`). Fighting convention forfeits the framework.
2. **Validation lives in Form Requests** (`make:request`) for any non-trivial endpoint - rules, authorization (`authorize()`), and typed access via `validated()`/`safe()`. Never trust `$request->all()` into a create/update.
3. **Mass assignment is a real vulnerability:** `$fillable` allowlists on every model (not `$guarded = []`), and pass `->validated()` data, not raw input, to `create`/`update`.
4. **Eloquent N+1s die by policy:** eager load (`with`, `load`) every relation a listing touches; enable `Model::preventLazyLoading(!app()->isProduction())` so violations throw in dev. `withCount`/aggregate loading over counting in loops; chunk (`chunkById`/`lazy`) for big scans; query-builder projections for read paths that don't need models.
5. **Authorization via Policies + Gates, invoked explicitly** (`$this->authorize('update', $post)` or middleware `can:`): route auth middleware proves identity, policies prove permission per resource - route-model binding + ownership check kills the IDOR class.
6. **Business logic in dedicated classes (Actions/Services), not controllers and not Blade:** controllers stay resource-shaped (7 RESTful methods; more verbs = new controller). API responses via API Resources (`JsonResource`) - never `->toJson()` on raw models (leaks columns).
7. **Queues for anything slow** (`ShouldQueue` jobs, mail, notifications): serialize IDs not models where staleness matters (`SerializesModels` re-fetches - know that), idempotent handlers, `failed()` methods and retry/backoff configured, Horizon or equivalent monitoring in production.
8. **Migrations are append-only history:** generated, reviewed, reversible `down()` where feasible; DB-level constraints (unique, foreign keys) alongside validation. Factories + seeders keep tests and local dev honest.
9. **Config discipline:** `env()` calls only inside `config/*.php` files (config caching makes `env()` return null elsewhere); `config()` everywhere else. `.env` never committed; `php artisan config:cache`/route/view caching assumed in prod.
10. **Use the escape hatches Laravel gives before dropping to raw:** scopes for reusable query logic, casts (incl. enum casts, `AsCollection`) for attribute types, accessors/mutators (`Attribute`) sparingly, events/observers with restraint (invisible side effects are a debugging tax - prefer explicit action classes).
11. **Blade escapes by default - keep it that way:** `{{ }}` always; `{!! !!}` only for sanitized/trusted HTML. CSRF (`@csrf`) on every form; signed URLs for public-but-tamperproof links.
12. **Tests: Pest/PHPUnit feature tests hitting real routes with `RefreshDatabase`,** factories for state, `assertDatabaseHas`, fakes for queues/mail/storage/events (`Queue::fake()` etc.) - Laravel's fakes beat mocking the container.
